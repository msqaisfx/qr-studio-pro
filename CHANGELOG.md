# Changelog

All notable changes to QR Studio Pro are documented here. The project follows semantic versioning once stable releases begin.

## [Unreleased]

## [0.9.1-beta.1] - 2026-10-27

- Smart Logo Studio 2.0 with independent container and visible-logo sizing.
- Aspect-ratio-safe contain and cover modes, transparent-padding trim, and edge-connected solid-background removal.
- Clean, Seamless, and Badge integration styles with opacity, padding, shape, and corner controls.
- Before/after preview, local undo/reset, low-resolution guidance, and expanded logo decode guard.
- Version 2 local project schema with automatic migration from existing version 1 projects.
- Professional GitHub documentation and real application screenshots.

## [0.9.0-beta.1] - 2026-10-25

- First public beta candidate with eleven QR content types.
- Local-first projects, templates, Scan Guard, five export formats, PWA installation, and offline operation.
- GitHub quality automation, release documentation, community templates, and Pages deployment preparation.
- This is a beta release, not a stable release; browser, camera, printer, and device behavior can vary.

## [0.1.0] - 2026-10-25

- Local-first React/TypeScript QR studio with Arabic RTL and English LTR interfaces.
- Eleven content types, QR shape and color controls, gradients, local logo processing, templates, and local IndexedDB projects.
- PNG, SVG, WebP, JPEG, and PDF export with independent QR decoding and Scan Guard checks.
- Installable PWA with offline application shell, local workflows, update controls, and lazy-loaded tools.

No backend, accounts, analytics, dynamic QR service, or remote project storage are included.
