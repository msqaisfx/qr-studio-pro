# Beta testing guide

Use synthetic or explicitly authorized data. Never request real passwords, private Wi-Fi credentials, confidential contact cards, wallet secrets, or proprietary logos.

## Suggested matrix

- Chrome, Firefox, Safari, and a separately installed Chromium build
- Current macOS, Windows, Android, and iOS devices available to testers
- Arabic RTL and English LTR
- Dark and light themes
- 375, 768, 1280, and 1920 CSS-pixel widths
- All eleven content types and five export formats
- Offline launch, update, install, project persistence, import/export, and cache refresh
- Real camera scans of screen and printed samples at conservative and stressful settings

Record browser/device versions, exact non-sensitive payload category, design settings, export format, expected result, actual result, and whether the file was decoded independently. A successful scan on one device is not a universal guarantee.

Report security issues privately. Public bug reports must use sanitized fixtures and must not attach private project JSON or user logos.
